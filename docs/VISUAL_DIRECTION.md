# Visual direction options

Pick **one** direction. Gameplan’s first viewport should feel brand-first (the name **Gameplan** is the hero signal), not a generic sports dashboard.

All options avoid the usual AI defaults (purple SaaS, cream+terracotta editorial cliché, broadsheet newspaper density).

---

## Option A — Night Match

**Feel:** Broadcast / stadium night. Focused, premium, calm energy.

- **Background:** Deep pitch green → near-black vertical gradient; subtle grass grain or stadium-light vignette (not neon glow spam)
- **Brand type:** Condensed athletic sans for **Gameplan** (e.g. something in the *Bebas / Oswald / Industry* family — we’ll pick an open license)
- **Body:** Clean grotesque for UI readability
- **Accent:** Single sharp signal color — electric lime or match-ball white on dark (one accent only)
- **Imagery:** Full-bleed pitch / crowd silhouette / ball-in-flight as the hero plane
- **Motion:** Slow ambient light drift; standings/fixtures stagger in; CTA press scale
- **Best if:** You want a product that feels like watching a night game

```
--bg: #07140f → #020403
--brand: #f4f7f2
--accent: #b8f53a
--muted: #8a9a90
```

---

## Option B — Matchday Press

**Feel:** Modern sports desk / magazine. Editorial but not newspaper-dense.

- **Background:** Cool stone / slate wash with soft paper texture; not flat white
- **Brand type:** High-contrast display serif for **Gameplan** only; UI stays sans
- **Accent:** Ink blue or signal red used sparingly (links, live dot, primary CTA)
- **Imagery:** Full-bleed photo of play or tunnel walk; text sits in a clear safe band, no sticker overlays
- **Motion:** Headline mask reveal; image subtle ken-burns; list rows fade/slide
- **Best if:** You want analysis + news to feel authoritative and readable

```
--bg: #e8eef2 → #d5dde3
--brand: #0b1b2b
--accent: #c8102e   /* or deep ink #0b3d91 */
--muted: #5c6b78
```

---

## Option C — Tactical Board

**Feel:** Coach’s board / whiteboard tactics. Analytical, distinctive.

- **Background:** Soft chalkboard green-gray with faint formation dots / grid (very subtle)
- **Brand type:** Technical mono or squared sans for **Gameplan**
- **Accent:** Chalk white + one marker color (orange or cyan) for selections/comparisons
- **Imagery:** Abstract pitch diagram as hero atmosphere OR real match still treated like a board photo
- **Motion:** Lines draw (formation / comparison connectors); markers pop on select
- **Best if:** Compare + predict should feel like the core product personality

```
--bg: #1e2a24
--surface: #2a3830
--brand: #f2f0e6
--accent: #ff7a18
--muted: #9aab9f
```
